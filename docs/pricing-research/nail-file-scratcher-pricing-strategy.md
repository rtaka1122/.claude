## 3. PSM分析（Van Westendorp Price Sensitivity Meter）設計書

### 目的

消費者が「安すぎ・安い・高い・高すぎ」と感じる価格の閾値を把握し、許容価格レンジ（Acceptable Price Range）と最適価格点（OPP）を導出する。

### 調査仕様

| 項目 | 内容 |
|------|------|
| 調査手法 | オンラインアンケート |
| 推奨調査会社 | マクロミル / FastAsk / インテージ |
| サンプル数 | n=200（猫飼育者） |
| スクリーナー | 「現在、猫を1匹以上飼育している」 |
| 属性割付 | 性別・年代を猫飼育者の実態構成比に合わせる |

### スティミュラス（提示物）

以下の情報を提示してから価格設問を実施する。

> **商品説明（提示文）**  
> TSUMETOGI MAFIAの「ヤスリ付き爪とぎ」です。  
> - 強化段ボール素材で耐久性3倍  
> - 研ぎくずが65%削減される設計  
> - 使いやすいシンプルな形状  
> - 爪の長さを整えるヤスリ機能付き  
>
> *(商品画像を提示)*

### 設問設計（4問）

| 設問No. | 質問文 | 変数名 |
|---------|--------|--------|
| Q1 | この商品がいくらだったら、**安すぎて品質が不安**になりますか？ | Too Cheap (TC) |
| Q2 | この商品がいくらだったら、**安くてお得**だと感じますか？ | Cheap / Bargain (C) |
| Q3 | この商品がいくらだったら、**高いけれど購入を検討**しますか？ | Expensive (E) |
| Q4 | この商品がいくらだったら、**高すぎて購入しない**と思いますか？ | Too Expensive (TE) |

**回答形式**: 自由記入（円）  
**提示価格レンジ目安**: 300〜5,000円

### 分析アウトプット

```
累積曲線の交点から以下を導出:
- PMC (Point of Marginal Cheapness)  : TC↑ と C↓ の交点 → 最低許容価格
- PME (Point of Marginal Expensiveness): E↑ と TE↓ の交点 → 最高許容価格
- OPP (Optimal Price Point)          : TC↑ と TE↓ の交点 → 最も抵抗が少ない価格
- IPP (Indifference Price Point)     : C↓ と E↑ の交点  → 「普通」と感じる価格
```

## 4. Gabor-Granger調査設計書（価格弾力性の把握）

### 目的

各価格帯での購入意向率を測定し、売上（価格×意向率）を最大化する価格を特定する。価格レンジは**2,980円まで**を視野に含め、プレミアム価格帯の市場ポテンシャルを検証する。

### 調査仕様

| 項目 | 内容 |
|------|------|
| 調査手法 | PSMと同一のオンライン調査内で実施 |
| 設問位置 | PSM設問の後に実施（価格アンカリング回避のため順序固定） |
| 提示方式 | モノアジック（1人に1価格のみ提示）または順序ランダムのシーケンシャル提示 |

### テスト価格帯

| グループ | 提示価格 | サンプル（n=200の場合） |
|----------|----------|------------------------|
| A | 680円 | n≒33 |
| B | 980円 | n≒33 |
| C | 1,480円 | n≒33 |
| D | 1,980円 | n≒34 |
| E | 2,480円 | n≒33 |
| F | 2,980円 | n≒34 |

### 設問文

> 「この商品が **〇〇円** で販売されていた場合、あなたはどうしますか？」
>
> 1. 必ず購入する  
> 2. おそらく購入する  
> 3. どちらとも言えない  
> 4. おそらく購入しない  
> 5. 絶対に購入しない

**購入意向率** = 「必ず購入する」＋「おそらく購入する」の合計率

### 想定分析結果（仮説）

| 価格（円） | 購入意向率（仮説） | 売上指数（価格×意向率） |
|------------|-------------------|------------------------|
| 680 | 88% | 598 |
| 980 | 74% | 725 |
| **1,480** | **55%** | **814** ← 売上最大化候補 |
| 1,980 | 38% | 752 |
| 2,480 | 22% | 546 |
| 2,980 | 14% | 417 |

### チャネル別クロス集計

購入チャネルを「ホームセンター / ペット専門店 / ドラッグストア・GMS / EC」で分類し、チャネルごとの価格弾力性を比較する。

### EC価格ポジショニング

```
つめまる       ▲ 6,980円  （独自形状・EC限定・高付加価値）
               │
本商品EC       ▲ 1,480〜2,480円  （機能訴求・セット販売）
               │

               │

```

### 価格維持（MAP）戦略

1. **希望小売価格の明示**: 全流通先に上代を文書で通知
2. **Amazonにおける最低広告価格（MAP）の設定**: 価格監視ツールの活用
3. **チャネル別SKU分けの検討**: バリエーション（色・本数・パッケージ違い）で価格棲み分け
4. **値崩れ発見時の対応フロー**: 通知→警告→取引条件見直し

### 2,980円到達の条件

以下の付加価値演出があれば、ペット専門店ECにて2,980円の実現可能性を調査で検証する：
- 高級感のある箱入りギフトパッケージ
- ニャンズカード（コレクション要素）との訴求強化
- 複数本セット（2〜3本）でのセット販売
